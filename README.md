## Services

## Updating the site

1. Export the new version as a single HTML file.
2. Rename it to `index.html`.
3. In this repo: **Add file → Upload files**, replace `index.html`, and commit.
4. Wait 1–10 minutes, then hard-refresh (Cmd/Ctrl + Shift + R).
